## After every Accepted (2 min)
1. Which pattern did it use? Open that note — or make one with the **Pattern** template (`Cmd+P` → *Templates: Insert template*).
2. Add the file to `solved:` in the note's properties.
3. If you got WA/TLE on the way, add one line to **My pitfalls**.

## Weekly (20 min)
1. Open *Revise next* above, pick the top pattern.
2. Pick one problem from its `solved:` list and re-solve it from a blank file, without looking.
3. Couldn't? Set `status: learning`. Could, fast? Move it up: `learning → comfortable → mastered`.

## Rules
- **Trigger**, **Core idea** and **My pitfalls** are written by me, never generated. Writing them is the point.
- Don't backfill all 520 files. Add old problems only when I revisit them.
